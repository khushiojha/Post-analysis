<h2 id="introduction">Introduction</h2>
<p>
Social Media Post Analysis is a web-based application that uses NLP techniques 
to extract keywords, generate hashtags, and assign confidence scores.
</p>

<h2 id="features">Features</h2>
<ul>
    <li>Keyword extraction</li>
    <li>Hashtag generation</li>
    <li>Confidence scoring</li>
    <li>JSON API support</li>
</ul>

<h2 id="technologies">Technologies Used</h2>
<ul>
    <li>Python</li>
    <li>Flask</li>
    <li>NLTK</li>
    <li>spaCy</li>
